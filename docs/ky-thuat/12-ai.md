# AI Report

## 1. Mục tiêu

Tạo nhận định kỹ thuật bằng tiếng Việt, dựa trên dữ liệu đã chuẩn hóa, có evidence.
AI **không sửa score/ranking**.

## 2. Prompt v2

- Trả lời hoàn toàn bằng tiếng Việt.
- Summary 3–4 câu, có ít nhất 2 chỉ số kèm giá trị.
- Mỗi điểm mạnh/điểm cần lưu ý có chỉ số + giá trị + ý nghĩa/ngưỡng.
- Nêu trade-off và giới hạn dữ liệu.
- Không đưa lời khuyên đầu tư.

## 3. Luồng model

```text
primary → fallback → template
```

- Primary lỗi/JSON invalid → fallback.
- Fallback lỗi → template tất định.
- Template v2 cũng phân tích theo số liệu.

## 4. Schema

Các field bắt buộc:

- `summary`
- `strengths`
- `weaknesses`
- `risk_flags`
- `missing_data`
- `evidence_ids`

`evidence_ids` phải nằm trong allowlist.

## 5. Budget và cooldown

- Cooldown 24 giờ/trader.
- Budget ngày/tháng cấu hình trong Settings.
- Dedupe theo hash dữ liệu đầu vào.

## 6. Giới hạn

- Model có thể trả sai/thiếu field → fallback.
- Không đảm bảo phát hiện mọi rủi ro.
- Không thay thế đọc số liệu gốc.

## 7. AI Agent chat (Phase 6b)

- Kiến trúc: `POST /agent/chat` (SSE) → `services/agent/orchestrator.py`
  (planner + tool loop tối đa 8 bước) → tools → verifier → lưu DB.
- Module: `schema.py` (ToolResult/AgentAnswer/SSE), `model_client.py`
  (OpenRouter native tool calling + JSON protocol fallback, primary → fallback 1×),
  `tools.py` (registry), `verifier.py` (số phải có evidence, chặn lời khuyên đầu tư).
- Reasoning: dùng chung `build_reasoning()` — `AI_REASONING_EFFORT=auto`
  (GLM 5.3 Flash `effort: low`, model khác `enabled: false`).
- Chỉ admin (`require_admin`); rate limit 20/phút; budget `ai_usage.feature='agent'`.
- Web search Tavily: cache Redis 24h theo hash query, timeout 10s; tắt khi thiếu key; snippet là untrusted data.
- Lưu `agent_sessions/messages/tool_calls/citations/feedback`.
- SSE events: `token/tool_call/tool_result/citation/warning/done/error`.
